# Task: v0.3.4 Support for /model and /thinking Commands in Rp-app
Feature: v0.3.4 Slash command suggestions and interactive prompts
Status: Completed

## Specs
S1 Slash Commands List and Thinking Command Addition:
- Include `"/thinking"` in the list of recognized `slashCommands` in `ChatScreen.kt` alongside `/clear`, `/compact`, `/model`, `/quit`, `/undo`, `/sdd-status`, `/help`.
- Recognize `"/th"` or prefix to suggest `"/thinking"` with chip replacing text with `"/thinking "`.

S2 Thinking Levels Chips and Contextual Suggestions:
- When text is `"/thinking "` or active command is `"/thinking"`, display suggestion chips for supported levels:
  `listOf("off", "minimal", "low", "medium", "high", "xhigh", "max")`.
- When user taps a level chip, replace composer text cleanly with `"/thinking $level"`.
- Support filtering when typing partial arguments (e.g. `"/thinking mi"` suggests `"minimal"`).
- Dismiss suggestions once a valid level is fully written.

S3 Interactive Prompts for Parameterless Execution:
- Sending `/model` or `/thinking` without arguments sends a `UserMessage` with `asCommand = true`.
- Rp-plugin dispatches an interactive `select` prompt (`prompt.open` / `PromptKind.SELECT`).
- Rp-app renders this prompt via `PromptBottomSheet` / `SelectBody` with radio/button options and sends `prompt.answer` with `Answer.option(id)`.

S4 Test Coverage:
- Unit / Robolectric Compose tests verifying `/thinking` slash command suggestion, level suggestions rendering, click substitution, and `/model` suggestion.
- Ensure all protocol and direct debug unit tests pass cleanly.

S5 Release Preparation (v0.3.4):
- Bump `versionName` to `0.3.4` in `app/build.gradle.kts`.
- Update `README.md`, `docs/INSTALACION.md`, and `docs/QA.md`.
- Commit with Conventional Commits and tag `v0.3.4`.
